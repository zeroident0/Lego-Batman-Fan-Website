# 🦇 Lego Batman Fan Website

A visually stunning, interactive fan website dedicated to the legendary Lego Batman. Built with a focus on high-end aesthetics, smooth animations, and a "premium" feel.

![Lego Batman Banner](public/logo.png) 

## - Experience the Dark Knight
This project is an exploration of modern web design, featuring:
- **Cinematic Visuals**: High-quality video backgrounds and immersive imagery.
- **Dynamic Animations**: Powered by **GSAP (GreenSock Animation Platform)** for scroll-triggered effects and interactive hover states.
- **Responsive Design**: Seamless experience across mobile, tablet, and desktop using **React Responsive**.
- **Modern UI**: Styled with **Tailwind CSS** for a sleek, dark-themed aesthetic.

## - Technology Stack
- **Frontend**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/) & [@gsap/react](https://github.com/greensock/react)
- **Responsiveness**: [React Responsive](https://github.com/yocontra/react-responsive)

## ⚙️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/zeroident0/Lego-Batman-Fan-Website.git
   cd Lego-Batman-Fan-Website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
